Knock 节点安装 · 过程演示

一台 Debian/Ubuntu 机器，从零到自启动，全程一条命令。下面是真实安装脚本会打印的东西。
root@node — sudo bash install.sh
Enter 跳过一步 R 重播
sudo ./install.sh安装，会问你四个问题（名字、地址、端口、要不要中继）
knock打开菜单：状态 / 节点码 / 日志 / 重启 / 开关中继 / 升级 / 卸载
knock status服务是否在跑、房间数、今天被敲了多少次
knock code把节点码打出来（发给朋友的那一串）
knock relay on|off开关数据中转，改完自动重启
knock logs -f跟日志
knock uninstall卸载，问你要不要留配置
演示是模拟输出，不是真机录屏。装完是 systemd 自启动（knock-node.service，Restart=always，enable 过）， 掉线自动拉起，重启机器也不用管。中继如果选了“要”，会和房间服务共用同一个端口，对外只开一个 30990。
