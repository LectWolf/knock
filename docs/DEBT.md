## 已补（2026-10-29）

- **`node_outdated` 有了名字**：之前版本对不上会伪装成 `relay_unavailable`，让人以为重试有用。
  现在它是第 6 个原因码，界面文案是「服务器版本太旧」。
- **退出应用会把房间摘掉**：房主 `close()` 时向节点发一次 `close`，不再留空房到 TTL。
- **复制门牌号有兜底**：WebView 里 `navigator.clipboard` 被拒时退回隐藏 textarea + execCommand。
- **节点列表从 GitHub 拉**：`api.github.com` 的 raw media type 优先（`raw.githubusercontent`
  在国内多半连不上），本地缓存 7 天，拉不到就用缓存，缓存也没有就提示手填。

## 协议与节点

6. **心跳没实现**：节点侧已按"最后一次 announce 续命"，但客户端还没有每 60 秒重发 announce 的循环。
7. **没有兼容期**：`knock/1` 直接被拒。升级后旧节点/旧房客只会看到"版本对不上"，没有过渡提示。
8. **节点 API 是明文 HTTP**：公网部署要 TLS；relay 的 TLS（ACME）要一个指向节点的域名。
9. **节点列表只到文件**：`nodes/public.json` 有了，但客户端没有拉取、缓存、过期标记，也没有校验 CI。
10. **控制帧没有金标向量**：`spec/invite-v1.tsv` 那套跨语言向量只覆盖邀请码，控制帧只有 Rust 单测。

## 工程

11. **没有 CI**：Go / Rust / 前端三套测试全手跑。
12. **e2e 脚本写死**：`scripts/transport.sh` 里固定了香港节点 IP 和门牌号，换节点要改脚本。
13. **没有发布流程**：Tauri bundle、节点二进制交叉编译、版本号统一，都还没有。
14. **没有远端仓库**：本轮才 `git init`，远端（GitHub 或自建）要定。

## 已补（2026-10-29 · 夜）

- **敲门即入场**：房客连上后先「报到」，房主当场试连自己的游戏端口——
  - 端口通 → 放行，房客立刻出现在「门里的人」（不用等 MC 客户端连进来）
  - 端口不通 → 回 `host_offline`，房客显示「屋里没人」，不再给一个假的"门开了"
- **两条路都不通时会卡死**：`PunchTimedOut` 在「自动绕路」策略下只表示"接着试中继"，
  而两条都失败后仍发它，界面永远停在"正在敲门…"。改成发 `RelayRejected`（终止）。
