# 公共节点列表

这份列表**只管发现，不管解析**：它让新用户省掉"粘贴一长串节点码"，不看这份列表也能用完整节点码连任何节点。

## 数据从哪来

- **不内置**：列表不随安装包走，客户端启动后从本仓库的 raw 地址拉一次。
- 拉到的结果缓存到本地；下次启动先用缓存，再在后台静默刷新。
- 从没联网成功过、又没有缓存时，节点页就是空的——只提示"粘贴节点码"，**不编造默认节点**。
- 缓存过期（默认 7 天）时标记为"可能过期"，但仍然可用：先能用，再求新。

## 收录标准

| 字段 | 含义 |
|---|---|
| `code` | 节点码（自描述编码，含地址/端口/指纹/校验） |
| `label` | 节点码里那份 4 字母标签，界面上显示成 `K7F2` |
| `name` | 人看的地名 |
| `relay` | 是否提供绕路 |
| `note` | 一句实话，比如"随时可能下线" |

**不收**：来路不明的节点、声称能加速的节点、要求注册账号的节点。
节点是用户自托管的，列表里的人随时可能关掉节点——所以列表是"候选"，不是"保证"。

## 加一个节点

改 `public.json`，提 PR。**合并前必须人工核对** `code` 能被 `spec/invite-v1.tsv` 那套编码解开（自动校验的 CI 还没接）。
